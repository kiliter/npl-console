# 单据图片修复

## 使用流程

填写新老单据号并加载。左右按当前显示页序对应，滚动按页序和页内位置双向联动；两边都有缩略图、滚动条和阅读进度。

- 左侧右键「在左侧复制为镜像页」：指定插入位置，在左侧增加完整页面副本，用于对齐新单据分页；原页、镜像页分别选取图片。
- 左侧右键「复制此页到右侧」：将整页插入新单据指定位置。
- 右侧右键「复制本页到指定页下面」：选择来源页和插入位置。输入 0 插在最前，其他数字表示插在该页下面。
- 左侧按住 Ctrl / ⌘ / Shift 多选图片，触屏长按追加选择。加入共享区后立即在右侧同序号页、原坐标预览。
- 右侧点击或右键图片「删除图片」，右键页面可「恢复本页删除的图片」。删除共享图层同时将它从共享区移除。
- 本地导入支持 PNG、JPEG、WebP，指定新单据页码、位置、宽度，保持比例并修正 EXIF 方向。共享区区分旧图和本地图片。
- 点击「应用」生成 PDF，再点击「保存到本地」。更改预览后需要再次应用，避免保存旧结果。

没有页码选择、待选择或跳过状态。页数相同时不提示；页数不同时只提示，仍可应用和保存已有页面。超出新单据页数的共享图片暂不写入，状态栏显示数量，补页后再应用。不自动镜像、复制或删除页面。

右侧画布用蓝色实线框标识共享旧图、紫色虚线框标识暂存拖入的图片、橙色实线框标识本地图片，并显示来源标签。边框和标签仅用于预览，不写入导出的 PDF。

双栏模式以蓝紫流光曲线持续连接「左侧原图 → 对应共享卡片 → 右侧预览图」，共享卡片两侧分别进出，当前页面和卡片可见时显示，随滚动实时更新，不需要悬停；同一行按图片左右位置分配上下错开的端点和弧线，避免重叠，加入顺序不改变路线；移除共享图片后对应连线消失。没有左侧来源的暂存/本地图片不连线。连线单独重绘，不重新解析或渲染 PDF，并遵循系统减少动画设置。

## 暂存与拖放

右侧图片右键选择「移入共享区暂存」，提取成功后在共享区显示紫色暂存卡片，同时从右侧原位置移除。提取失败不删除原图。支持原 PDF 图片及当前共享区叠加图层。

将暂存卡片拖入右侧任意页面，松开鼠标的位置作为图片中心。保留原尺寸与旋转，超出页面时等比缩小并限制在页内；拖到页面外不改变原状态。放置后仍可从共享区再次拖动以调整位置或跨页移动，不重复复制图片。

暂存与拖放只改变画布预览，点击应用后才写入 PDF。尚未放置的暂存图片不写入，状态栏显示未放置数量；原位置删除仍会生效。移除暂存卡片不自动恢复原图，需要时可右键原页恢复本页删除的图片。暂存仅属于当前会话，重新加载或退出会清空。

## 画布预览与生成

右侧显示独立、稳定的底稿缓存。共享区图片由 Flutter Canvas 按实际尺寸、坐标和旋转变换叠加；加入、移除和导入不会生成 PDF，也不会清空右侧页面缓存。删除或替换原图时，仅重新渲染受影响页面的背景图层，不序列化整份单据，保留文字及其他图像。

点击应用后，才从底稿执行图片删除与批量写入，一次打开、一次序列化。失败不提交部分结果。同坐标的多个共享图层按共享区顺序叠加，匹配的底稿原图先移除，预览与导出的遮挡顺序一致。重复应用不重复叠图。应用完成后画布继续使用原有底图和图层，不重新加载右侧单据。

镜像或整页复制会更改页面结构。旧图跟随左侧来源页移动，始终对应右侧当前同序号页；本地图片和原图删除记录跟随右侧原页面。右侧自复制包含该页的待应用图层及删除效果。

## 性能与边界

页面懒加载，合并同页请求，缓存首屏和最多五个其他页面，额外页面 PNG 缓存限 24 MiB。缩略图独立以 100 像素宽渲染，最多缓存 40 页。流光遮罩每帧统一计算，静止曲线复用路径度量；PDFium 操作与 PNG 编码在工作 isolate 执行；画布图片仅在可见页解码并在离屏后释放。

共享区最多 30 张、合计 64 MiB。本地单图不超过 20 MiB 或 4000 万像素。保存为 `<新单据号>_修复.pdf`，不自动覆盖后台 OBS。取消保存保留编辑结果；切换环境或重新加载会清空会话。
