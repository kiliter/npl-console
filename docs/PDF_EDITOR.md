# 在线单据编辑

## UI 与操作

桌面沿用已选高保真三栏：来源 PDF、共享素材、目标 PDF。手机沿用已选底部抽屉布局，来源与目标通过页签切换。编辑入口为全局「在线单据编辑」Tab，不改变查询页当前选中的工单。

1. 选择「直接编辑」或「基于老单据编辑」，输入新单据号（第二种模式还需输入老单据号）。
2. 加载单据。两个单据分别使用现有工单查询和 OBS 读取接口，无新增服务端契约。
3. 在来源页点击一个图片对象，点击「加入共享区」。桌面拖动素材到目标 PDF；手机或桌面也可先点素材，再点目标页面放置。
4. 选择目标图片后移动、从四角等比缩放、替换或删除。选择「编辑文本」后点原有文字块，再点「编辑选中文字」。复制页面将独立副本插在当前页之后。
5. 保存 PDF 副本。取消系统保存框不清除脏状态；成功保存后更新当前版本状态。这里不会上传或修改 OBS。后台覆盖仍通过原有上传修复入口，执行原有备份与三级确认。

## 实现

- `core/pdf_editor/pdf_engine.dart`：通过公开 `PdfrxEntryFunctions.compute` 在 PDFium 工作 isolate 内执行底层编辑，避免字体回调跨 isolate 崩溃。不从 UI 保留或传递 native 指针。
- 每个编辑命令从当前 PDF 字节打开独立文档，成功生成并重新读取后才提交；失败保留原版本。文本/图片操作不将整页栅格化；页面 PNG 仅供编辑视图预览。
- 文本使用 SIL OFL 字体和显式 ToUnicode/CIDToGID 映射，避免「文」被提取成部首「⽂」等字体反向映射错误。修改后的文字仍可搜索和提取；保留位置、字号、文字变换与填充颜色，编辑字体统一使用内置字体。
- `core/pdf_editor/edit_session.dart`：独立来源/目标文档、会话共享素材、撤销/重做及保存状态。历史最多 8 个版本 / 64 MiB（至少保留一个撤销版本）；共享素材最多 30 张 / 64 MiB。素材保留独立 PNG 字节，切换或关闭来源文档后仍可复用。
- 页面和对象位置按 PDFium 的 page/device 坐标转换，考虑页面旋转及裁剪。来源提取仅处理图片对象，按原像素尺寸渲染并保留 alpha mask，不截取整页。
- 页面复制使用原生跨文档导入，避免锁定 pdfrx 版本中页面重排器的重复页索引错误。
- 查询加载沿用原有 RS256 JWT、请求白名单、接口记录与强制刷新机制。不调用查询页 `_start()`，不清空工单选择。环境切换清空会话，异步结果使用代次失效；关闭编辑器不接受迟到结果。

## 明确的兼容边界

- 文本编辑针对 PDF 原生文字块。扫描图中文字、转曲文字需其他引擎或 OCR；本次不提供。文字可能按单字或多块保存，按实际 PDF 对象选择，不承诺 Word 式段落重排。换行输入明确拒绝，缺字不静默输出空白。
- 组合 Form XObject 内图片可提取、替换。PDFium 公开接口不能可靠保存任意嵌套对象的坐标流修改，因此此类图片不显示移动手柄，删除或移动时明确拒绝。可提取到共享区后作为新的顶层图片插入，新增图片支持移动和缩放。组合对象内文字不支持直接修改。
- 替换图片保持原矩阵和尺寸，长宽比不同可能拉伸；新增图片等比缩放。图片输入限制 20 MiB / 4000 万像素。
- 密码 PDF 暂无密码输入入口。遵守 PDF 内容修改、组装和提取权限，不移除文档安全设置。编辑后的副本不承诺保留已有数字签名有效性；签字图片与密码学数字签名不是同一概念。
- 当前保存为本地副本，未增加编辑器内直接上传；不能将保存提示理解成后台覆盖成功。

## 字体

`assets/fonts/NotoSansSC-Regular.ttf` 来自 Noto CJK 的 Noto Sans SC，按 `wght=400` 实例化静态字体。`NotoSansSC.cmap.json` 是该二进制的 Unicode → glyph id 映射。两者必须一起更新。授权见同目录 `OFL.txt` / `NOTICE.txt`。字体约 11 MiB，会增加安装包和首次文本编辑后 PDF 的体积。

## 验证

固定 Flutter 3.44.7 / Dart 3.12.2：

```sh
flutter pub get
flutter analyze --no-pub
# 指定本平台 PDFium 动态库，macOS 可使用原有 native_assets 构建结果：
PDFIUM_PATH=/absolute/path/to/libpdfium.dylib flutter test --no-pub
```

Linux hook 会生成 `.dart_tool/hooks_runner/shared/pdfium_dart/build/.../linux-x64/libpdfium.so`；Windows 使用 `pdfium.dll`。新编辑测试有自动发现辅助函数。原有 macOS plist 迁移测试依赖系统 `plutil`，只在 macOS 执行，其他平台注明跳过。

真实 PDF 测试覆盖：中文替换和提取一致性、图片增删改及 alpha、旋转页坐标、组合图片提取/替换及拒绝不支持的坐标修改、独立页面复制。UI 测试覆盖 390×844、800×650、1440×1024，实际点击提取、放置、撤销、复制以及保存取消/成功；导出字节重新打开验证页数。会话测试覆盖环境变化和关闭时的迟到结果隔离。

`test/fixtures/editor.pdf` 使用演示文字与生成的网络示意图，不含真实单据、联系方式或业务数据。UI 渲染截图写到忽略的 `build/editor-qa/`。这些测试不能代替四端真机的系统文件选择器、平台构建及真实业务 PDF 验收。
