## v1.6.2 · 2026-11-03 · Windows 专项修复

本次仅提供 Windows x64 安装包，其他平台暂不发布。

- 已下载的 PDF 统一直接内存加载，绕过超过 1MB 后进入 Windows 异步读取回调的路径，处理多页单据后续页面持续等待的风险；阅读器与单据修复共用此策略。
- 左右文档的页面及缩略图渲染统一限制同时打开的文档数量，减少多份大文档和位图同时驻留。
- 新增独立程序运行日志，记录启动环境、版本、生命周期、Flutter/异步异常、经常见凭据脱敏的控制台输出，以及 PDF 页面打开、解析、渲染、编码、释放等阶段。
- 在「接口记录」中显示可复制的「程序运行日志」完整路径；文件位于应用支持目录的 runtime-logs 子目录，按运行会话写入 runtime-*.jsonl，每次运行最多保留五个约 4MB 分卷。
- 页面加载超过 20 秒时显示提示并记录阶段，不强行释放仍在执行的原生任务。

完整解压 ZIP 后运行 npl_maintenance.exe。请用原先超过 1MB 的多页单据验证；若仍有等待，提供程序运行日志及对应接口日志。Dart 运行日志不等同于 Windows 原生崩溃转储。
