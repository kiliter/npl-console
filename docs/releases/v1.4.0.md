# v1.4.0 版本说明

新增日志文件下载、多环境切换与内置门户网页。

- 日志文件：浏览服务 / web 全部副本的 `/usr/local/logs`，按 1.5MB 分片下载并直接写入磁盘，文件轮转时按 fileKey 自动续传。
- 批量下载：按 `ls *.log` 风格的通配符过滤全部副本的文件，逐个下载到所选目录，按 Pod 分目录，失败原因写入「下载失败清单.txt」。
- 多环境：设置中可配置多个环境（服务地址与可选 web 地址），顶栏或手机菜单快速切换；旧版单服务地址自动迁移为「默认环境」。
- 内网 / 外网门户：链接以私钥加密内置，导入密钥后在应用内网页打开。
