# v1.6.0 版本说明

「在线单据编辑」调整为「单据图片修复」，围绕新老单据对照、图片修复和本地保存简化操作。

- 双侧连续滚动、缩略图和进度条，按显示页序联动；页数不同时只提示，由用户复制页面补齐。
- 支持旧页镜像、旧页复制到新单据、新单据页内复制、右侧图片删除和本地图片导入。
- 共享区支持多选旧图及暂存右侧图片，暂存图片可拖回任意新单据页面；用来源边框区分图片。
- 共享区变化通过画布实时预览，点击「应用」后统一生成 PDF，再保存到本地；编辑不会自动覆盖 OBS。
- 常驻流光连线按「左图 → 共享卡片 → 右图」展示，同排路线错开；复用遮罩和曲线度量，减少动画重复计算。
- 修复同坐标图层导出丢失、导出图层顺序与预览不一致，以及坐标微差导致删除或暂存后原图恢复的问题。
- 配置和业务签名密钥迁移到用户 `.config/npl-maintenance`，验证成功后清理旧副本，迁移中断可重试。macOS/Linux 目录权限 700、文件权限 600；业务密钥本身不作废。
- 新增接口结果表查询及会话内 SM4 解密；解密在后台执行，密钥和本地解密明文不写入配置及请求日志。

共享区、暂存图片和未应用操作只在当前会话保留。关闭或重新加载前请先应用并保存需要保留的结果。
