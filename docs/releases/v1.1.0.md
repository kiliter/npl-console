# 版本日志

## v1.1.0 · 2026-09-18

新增数据表查询与全量报文加载。

- 新增「数据查询」：按 WO_INFO / WO_BIZ_INFO / WO_SIGN_INFO / WO_PIC_INFO 四张表直查，复用既有只读接口，不新增后端接口。
- 查询条件支持单据号、受理流水、业务月份和图片序号（仅图片表）；受理流水须搭配业务月份。
- 查询结果以表格展示，点击行查看完整字段，支持逐字段或整份 JSON 复制。
- 报文文件列表新增「全量报文」：选中后调用 `/agapi/biz/downloadBiz`（仅传单据号），JSON 内容由报文解析器展示，可保存为文件。
- 接口记录完整覆盖数据查询与全量报文请求；全量测试 34 项。

签名限制与安装步骤见 README；Release 构建不代表 App Store 上架或系统默认信任。

- 四端统一由 GitHub Actions 构建；推送版本标签后自动测试、构建并发布完整 Release。
