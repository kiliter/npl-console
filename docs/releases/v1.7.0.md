## v1.7.0 · 2026-11-06

新增「批量修复」，按订单号自动补齐最新单据缺失的签字和证件图片；单据图片修复页识别页面类型，界面整体改版。

### 批量修复（仅 Windows、macOS）

- 在表单中逐个录入订单号（2 开头的 18 位 CRM 受理流水，可一次粘贴多个），提交后只读查询近三个月单据并下载。
- 自动识别最新一笔单据中爱知签字页、风险抄录页、地市协议页缺失的签字和证件图片，从同订单号的历史单据取对应图片补上；业务受理单页面不检查。签字区、抄录区、证件格位置取自 currency_agree_23、copy_agree_new 模板。
- 证件图片和地市协议页的签字只能对照历史单据判断：历史签字页与最新签字页共享证件，且历史页多出的证件在最新单据中找不到时才补；地市协议页按正文找到同一份协议后，补齐同一位置缺失的签字。
- 修复件内置压缩：合并重复对象、精简嵌入字体，图片不做改动，逐页渲染与原件一致，常见 5～6MB 单据压到约 1.5MB。只有仍超过上传接口 2MB 限制时，才逐级把非 JPEG 图片转为高质量 JPEG 或降低分辨率。
- 预览修复前、修复后与来源页，虚线框标出补入位置；可取消个别修补项后重新生成。查询、下载或分析失败的订单显示「重试」。
- 「上传到生产」：先重新下载线上原件作备份，经核对目标、确认备份、手动输入口令（禁止粘贴）和最终确认后逐个上传，每份上传后回读校验。某一份失败不影响其他文件，失败的可单独重试；已上传成功的单据按上传历史自动剔除，不会重复上传。
- 文件与日志保存在「下载/单据批量修复/<时间>/」：originals 原件、output 修复件（单据号-订单号.pdf）、repair.jsonl 修复日志、uploads/<批次> 备份与上传日志；所有批次的上传记录汇总在「下载/单据批量修复/上传历史.jsonl」。日志不记录 JWT 和文件内容。

### 单据图片修复

- 页眉和缩略图显示页面类型：业务受理单（标题文字或标题图片）、爱知签字页、风险抄录页、地市协议页。
- 三栏分隔条可拖动调整宽度，双击恢复；左右单据同步缩放（按钮、Ctrl/⌘ + 滚轮、触控板捏合）和横向滚动，缩略图条同步并跟随当前页。
- PDF 渲染改为按优先级调度并并行编码，只读文档在后台常驻复用，打开和翻页更快；大报文后台解析，搜索防抖，界面按需局部刷新。

### 界面

- 工单查询、数据查询、工单详情、日志、设置、文件预览、报文浏览等面板按新设计统一配色与布局；单据修复页重做顶部输入区、操作按钮、图例与操作说明，栏头显示「待应用 / 共 N 页」。

批量修复的上传会覆盖生产 OBS 上的单据，修补和重新压缩会使原单据的电子签章域失效（页面显示不变），上传前请在预览中核对。Windows 版批量修复首次发布，遇到问题请提供批次目录中的 repair.jsonl、upload.jsonl 和程序运行日志。
