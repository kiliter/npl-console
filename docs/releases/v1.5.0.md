# v1.5.0 版本说明

新增「在线单据编辑」，支持直接编辑目标单据，或从老单据提取图片、放入共享素材区后编辑新单据。

- PDF 原生文字块编辑，新增/替换图片，顶层图片移动和等比缩放，复制页面，撤销/重做及保存 PDF 副本。
- 桌面三栏工作台；手机来源/目标单据切换与底部共享素材抽屉。
- 修复图片表受理流水查询：使用 `picSeq`，不再发送 `sysAccept`；长流水和前导零原样保留。
- 本地保存不自动覆盖 OBS；需要回传时继续走原有备份及三级确认的上传修复入口。

文字编辑针对 PDF 原生文字块，不提供扫描件 OCR 或段落自动重排。组合对象内的文字不支持直接编辑；组合图片可提取/替换，移动时先提取为共享素材再插入。完整说明见仓库 `docs/PDF_EDITOR.md`。
